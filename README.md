# 🚗 Java Car Simulator

Simulador de veículo desenvolvido em Java, com foco nos fundamentos da Programação Orientada a Objetos (POO). O projeto permite interagir com um carro por meio de um menu no console, controlando seu funcionamento, velocidade, marchas e direção.

## ⚙️ Funcionalidades

- Ligar e desligar o veículo com validações.
- Acelerar e desacelerar.
- Subir e reduzir marchas.
- Verificar a velocidade atual.
- Simular curvas para a esquerda e para a direita.
- Exibir informações do veículo, como marca, modelo, velocidade, marcha e estado atual.
- Validar operações de acordo com o estado do veículo.

## 🛠️ Tecnologias utilizadas

- **Java** — linguagem de programação.
- **Programação Orientada a Objetos (POO)** — classes, objetos, encapsulamento, construtores e métodos.
- **Git e GitHub** — versionamento e hospedagem do código.

## 📚 Objetivo do projeto

Praticar lógica de programação, organização de código e conceitos de Programação Orientada a Objetos em Java, aplicando-os no desenvolvimento de uma aplicação interativa.
